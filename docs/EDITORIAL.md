# Editorial workflow

DRAFT -> REVIEW -> SCHEDULED -> PUBLISHED -> ARCHIVED

Roles:
SUPER_ADMIN, ADMIN, EDITOR, SUB_EDITOR, REPORTER, PHOTOGRAPHER,
VIDEO_EDITOR, TRANSLATOR, FACT_CHECKER, MODERATOR, GUEST_AUTHOR.

Every published story should have:
- English and/or Kannada translation
- headline and subtitle
- body
- category
- author
- publish/update timestamps
- featured image + alt text
- SEO title/description
- canonical URL
- tags
- fact-check state when applicable
